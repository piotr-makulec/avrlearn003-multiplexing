# avrlearn003-multiplexing
Piotr Makulec, 26NO2025
This repo is a part of my AVR self-learning journey.
The code was written in C for ATmega328p (Arduino).
The code allows to control the FJ5361BH triple 8-segment LED display.
Timer interrupt is used to switch between switching on the digits every 2.5 ms.
This way the human eye sees three digits displayed constantly.
